## Привет 👋

Меня зовут Fred. Пишу ботов и автоматизацию для бизнеса: **ВКонтакте, Telegram,
LLM-агенты, интеграции с API**. Не учебные примеры — рабочие системы, которые
кто-то использует каждый день.

Стек: **Python** (основной), **JavaScript / Node.js**, SQL, REST и WebSocket,
OpenRouter / локальные модели (Ollama).

---

### Что я делаю

- **Боты для приёма заказов и заявок.** Диалог с состоянием, корзина, расчёт цены
  и доставки, печать чеков, уведомления. Бот, который не «здоровается по кнопке»,
  а ведёт клиента до оформленного заказа.
- **AI-агенты поверх кнопочных сценариев.** LLM отвечает на свободные вопросы
  («а вы возите в пригород?»), но не ломает бизнес-логику: заказ всё равно идёт
  по проверенному сценарию.
- **Библиотеки и инструменты.** Когда задача упирается в отсутствие нормального
  решения — пишу его сам и отдаю в открытый доступ.
- **Автоматизация рутины.** Сбор данных, разметка и приоритизация, отчёты,
  интеграции между системами через API и вебхуки.
